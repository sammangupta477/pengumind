## 📌 Overview
**PenguMind** is an interactive AI web application built with **Python** and **Streamlit** combining:
1. **Pip (Penguin Virtual Assistant):** Live web-connected conversational assistant (Google News RSS + Wikipedia API) with natural-language route control.
2. **Interactive AI Search Visualizer:** Real-time comparison of **A\***, **BFS**, **DFS**, **Hill Climbing**, and **Simulated Annealing**.

## 🛠️ Tech Stack
- **Frontend & Hosting:** Streamlit, Streamlit Community Cloud
- **Backend & AI:** Python 3, Groq LLM API, Google News RSS & Wikipedia REST API

## 🚀 Run Locally
```bash
git clone [https://github.com/sammangupta477/pengumind.git](https://github.com/sammangupta477/pengumind.git) && cd pengumind && pip install -r requirements.txt && streamlit run app.py
```
